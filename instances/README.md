# Instances locales

Chaque dossier correspond a la valeur `id` d'une entree de `distribution.json`.

- `BuildLauncher-1.21.11/mods/` : mods locaux de l'instance Build
- `BuildLauncher-1.21.11-Modde/mods/` : mods locaux de l'instance complémentaire Build Moddée
- `Handaria-1.21.11/mods/` : mods locaux de l'instance Handaria

Les modules declares dans `distribution.json` restent geres et telecharges par le launcher.
